# Bucheon AI Library

자연어로 책을 찾고, 도서관별 소장 및 대출 가능 여부를 확인할 수 있는 AI 도서검색 서비스입니다.

이 프로젝트는 공개된 유사 서비스의 아이디어와 사용자 흐름만 참고하며, 코드·문구·이미지는 복제하지 않고 처음부터 자체 개발합니다. 초기에는 부천시 도서관 적용을 목표로 하되, 향후 다른 도서관에도 적용할 수 있는 범용 구조로 설계합니다.

## 현재 구현 현황

- React·Vite 기반 반응형 검색 화면
- mock 데이터 기반 자연어 키워드 검색
- 도서별 소장 도서관 및 대출 가능 여부 표시
- 대출 가능한 도서만 보기
- 로딩·빈 결과·오류 상태 화면
- mock과 실제 연동 기능의 명확한 구분

## 개발 방향

- 프론트엔드: React + Vite
- 도서 검색: 도서관 정보나루 Open API 연계 레이어
- API 승인 전: mock 데이터로 기능과 화면 검증
- 음성 검색: Web Speech API 기반 한국어 STT
- 자연어 해석: LLM과 백엔드 연계를 단계적으로 추가
- 보안: API 키와 인증정보를 프론트엔드 코드에 저장하지 않음
- 표기 원칙: 실제 연동 기능과 mock·시연 기능을 화면과 문서에서 명확히 구분

## 개발 순서

### Phase B — 도서검색 기반 구축

1. 반응형 검색 UI
2. mock 데이터 기반 검색 결과
3. 정보나루 Open API 서비스 레이어
4. 도서관별 소장 및 대출상태 표시

### Phase C — AI 대화형 검색

1. 한국어 음성입력(STT)
2. 일상언어 질의의 검색조건 변환
3. LLM 및 백엔드 연계
4. ALPAS·SSO 등 기관 시스템 커넥터 확장

## 기본 준수사항

- 웹 접근성·웹 표준·브라우저 호환성
- 개인정보 보호와 공공기관 정보보안 기준
- Open API 및 소프트웨어 개발보안 기준
- 외부 서비스 장애와 API 제한을 고려한 예외 처리
